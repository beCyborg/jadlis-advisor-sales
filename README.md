# Звонок закончился, а через день ты помнишь настроение, а не место, где всё поехало

Разбор идёт по расшифровке с пронумерованными репликами: каждая находка привязана к номеру, а
номер реплики сверяется с файлом расшифровки поиском по строке до того, как
совет соберёт вердикт.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-sales@jadlis
```

Ключей и чужих подписок не нужно; настройка одна — `MEMORY_DIR`, папка, куда уходят вердикты,
журнал прогонов и профиль сделки: за её пределы совет не пишет ничего.

![Находка совета указывает на конкретную реплику расшифровки, а не на пересказ звонка](docs/img/hero-jadlis-advisor-sales.webp)

Текстом: слева расшифровка с пронумерованными репликами, справа — короткий список ходов на
следующий звонок, и от каждого хода идёт стрелка к той реплике, из которой он вырос.

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Как это работает

![Расшифровка и профиль сделки уходят в слои-советники, проверка анкоров и скептики режут спорное, на выходе вердикт файлом](docs/img/how-jadlis-advisor-sales.webp)

На входе — расшифровка с размеченными сторонами — делаешь её ты, не плагин — (или описание
застрявшей сделки) и профиль:
тип продажи, порядок чека, кто в решении, против кого играем.
Внутри — слои читают вход порознь, каждый номер реплики сверяется с файлом расшифровки поиском
по строке, куратор выделяет спорные утверждения, и по каждому проходят три скептика.
На выходе — вердикт файлом в твоей папке: хронология с номерами реплик, ходы и признак, по
которому сделку пора отпустить.

Текстом: расшифровка и профиль сделки → слои читают порознь → проверка номеров реплик и скептики
по каждому спорному утверждению → вердикт файлом с ходами и критериями дисквала.

Выбирается режим флагом: `--call` разбирает расшифровку звонка, `--deal` ставит диагноз
застрявшей сделке по описанию, `--verdict` оценивает готовый артефакт (скрипт дискавери, питч,
холодное письмо, КП, письмо после демо), `--write` пишет текст — бриф, три драфта в разных рамках,
критика советников по типу текста, синтез финала. Флага нет — режим определяется по запросу, а
неоднозначный случай совет переспрашивает.

Отпущенное скептиками не попадает в ходы: опровергнутое утверждение выбывает, спорное уходит в
раздел «Против» с пометкой. Полный ростер не запускается ни в одном режиме — под тип задачи
берётся подмножество, потому что нерелевантные книги производят правдоподобный шум. Ростер
собран из шестнадцати советников по двадцати одной книге: часть слоёв держит по две книги сразу,
и тогда у каждой свой суффикс в теге, чтобы два источника одного советника не считались двумя
голосами.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин advisor-sales из маркетплейса jadlis.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. claude plugin install advisor-sales@jadlis --config MEMORY_DIR=~/advisors-memory
3. claude plugin list — покажи мне строку про advisor-sales и его версию.
MEMORY_DIR — это папка на моём диске, куда совет пишет вердикты, журнал и профиль сделки.
Путь выбираю я: спроси меня до второй команды и подставь мой ответ вместо ~/advisors-memory.
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй,
скажи, что именно пропустил, и иди дальше.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-sales@jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall advisor-sales@jadlis --keep-data`.

Папку памяти можно задать прямо в установке — `claude plugin install advisor-sales@jadlis
--config MEMORY_DIR=~/advisors-memory`. Значение по умолчанию — `~/advisors-memory`; скелет папки
(журналы, профили, свайп-файл) разворачивается при первом прогоне и существующие файлы не трогает.
Поменять путь потом — через `/plugin` → advisor-sales → настройки либо переустановкой с
`--config`. Если настройка не подставилась, первый же прогон останавливается и говорит об этом:
в рабочую папку проекта совет не пишет.

**в) Короткая команда.** Открой Claude Code в папке, где работаешь, и набери:

```
/advisor-sales --call <путь к расшифровке звонка>
```

Остальные три режима — `--deal`, `--verdict`, `--write`, теми же флагами у той же команды;
под-скиллов на режимы нет. Не находится — сверь имя строкой `claude plugin list`.

## Границы, стоимость, обновление

**Чего не делает.** Не ищет клиентов и не строит воронку — это `advisor-influence`. Не пишет
лендинги, рассылки и продающие посты — это `advisor-copywriting`. Не назначает цену продукту — это
`advisor-product`. Вебинары и продажу со сцены не берёт вовсе: контур отложен, совет откажет вслух.
Не размечает стороны в расшифровке за тебя: реплики не размечены и не восстанавливаются — режим
вслух деградирует до оценки по саммари, потому что привязывать находки становится не к чему. Не
хранит расшифровки молча: копия реального звонка уезжает в папку памяти только по твоему
подтверждению и после того, как ты вычистил имена и компании, иначе рабочая папка прогона
удаляется целиком. И не ведёт сделку за тебя: ход выполняешь ты, ответственность за исход остаётся
на тебе.

Теги вида `[PREFIX:CODE]` указывают на блок конспекта внутри плагина, а не на страницу книги: это
привязка, по которой рекомендацию можно открыть и оспорить, а не библиографическая ссылка.
Границы использования конспектов — в `NOTICE.md`.

**Что нужно.** Ключей не нужно, внешних подписок и CLI — тоже: всё считается внутри Claude Code, из
твоей квоты. Нужны папка памяти (`MEMORY_DIR`) и, для `--call`, расшифровка звонка с размеченными
сторонами — делает её не плагин. Для `--write` бриф требует дословных фраз клиента и реальных
пруфов: кейсы и цифры совет за тебя не сочиняет.

[уточнить] — минимальная версия Claude Code в репозитории не зафиксирована; скилл и его
агент-воркер объявлены на Opus с высоким effort, поведение на плане без Opus не проверялось.

**Порядок расхода токенов.** Тяжёлый прогон — десятки субагентов из твоей квоты: слои читают вход
параллельно, дальше куратор, скептики по каждому спорному утверждению и валидатор. Дороже прочего
идут `--call` и `--verdict`, легче — `--deal` и `--write`; смету прогона совет показывает до
запуска. Частично совет не деградирует: исчерпанное сессионное окно валит фан-аут целиком — линзы
возвращают отказ, вердикта нет, поэтому советы подряд в одно окно не планируются. Один вопрос, одна
формулировка, одно возражение — совет не созывается вовсе: отвечает одна линза.

**Проверено там, где я работаю:** мой Mac, моя подписка, мои задачи. Где ещё это работает —
[уточнить].

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update advisor-sales@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall advisor-sales@jadlis --keep-data && claude plugin install advisor-sales@jadlis
```

Этот репозиторий собирается генератором из приватного источника: правка, сделанная прямо здесь,
релиз не переживёт — CI сверяет содержимое с хешем в `SHARED_FROM.txt`. Issue открывай тут, чинится
оно в источнике.
