# Deal Protocol — режим DEAL (совет по застрявшей сделке)

Вход: описание сделки + DEAL_PROFILE (оба экрана deal-profile-gate.md). «Не знаю» на
вопросах экрана 2 — сам по себе диагноз (провал дискавери / нет чемпиона), фиксируется
как находка.

## Ростер

3–6 советников ПОСЛЕ жёстких гейтов. Маршрутизация по «где застряло»:

| Симптом | Ядро ростера |
|---|---|
| после дискавери / вялый интерес | gap, spin, khalsa |
| после демо/КП тишина | jolt, selling-with*, dunford-pitch |
| переговоры о цене | negotiation, voss, weiss* |
| постоянно откладывают | jolt, qsl*, blount-objections |
| непонятно, была ли сделка вообще | khalsa, qsl*, founding* |

`*` — если проходит гейты профиля. N_built < 4 → совет не созывается: отдать
standalone-советника по симптому.

## Слои диагностики (каждый советник проверяет свой слой)

1. Была ли это сделка вообще (квалификация задним числом)?
2. Оцифрован ли разрыв/проблема — знает ли клиент цену бездействия?
3. Есть ли чемпион и продаёт ли он внутри без нас?
4. Против кого играем реально (конкурент vs статус-кво vs страх ошибки)?
5. Совпадает ли процесс продавца с процессом закупки клиента?

## Формат хода в вердикте DEAL — жёсткая четвёрка

Каждая рекомендация обязана нести все четыре поля:

```
### {N}. {Диагноз}: {одной фразой что сломано}
**Ход:** {конкретное действие/письмо/звонок с формулировкой} [ТЕГ]
**Сигнал:** {что мы увидим в течение X дней, если диагноз верен и ход сработал}
**Критерий дисквала:** {что означает «сделки нет — перестать тратить время»}
```

Ход без критерия дисквала не выпускается: совет по застрявшей сделке, который не умеет
сказать «отпусти», — машина по производству ложной надежды.

## Скептики (3 именованные линзы + ротационная)

1. **Альтернативная гипотеза**: те же факты объясняются проще? (клиент вежливо ушёл;
   бюджет умер; чемпион сменил работу). Если альтернатива не хуже — claim contested.
2. **Наблюдаемый сигнал**: диагноз проверяем? Если ни один наблюдаемый факт не может
   его опровергнуть — это не диагноз, refuted.
3. **Цена вмешательства**: ход может добить сделку? (дожим при страхе ошибки усиливает
   страх — JOLT). Риск/выигрыш хуже бездействия → refuted.
Ротационная — **сикофантность**: не повторяет ли вердикт версию пользователя о том,
почему сделка застряла?

## Формат вердикта DEAL

```markdown
# Сделка: {псевдоним} — диагноз и ходы

> [!info]- {DEAL_PROFILE + сколько висит + советников N/M + исключены гейтами}

## Вердикт одной строкой {главный диагноз + вероятность что сделка жива: высокая/средняя/низкая}

## Диагнозы (ранжированные) {формат жёсткой четвёрки, ≤3 диагноза}

## Ответы «не знаю» как диагноз {если были на интейке}

## Чего НЕ делать {антипаттерны — особенно привычный дожим}

## Дедлайн решения {дата: если к ней нет сигналов — критерии дисквала сработали}

## Где совет мог просто согласиться
```
